### Unity

A separate temporary Unity 6000.4.1f1 project was used so no existing user project was modified. MCP for Unity v10.3.0 was installed only in that qualification project.

Windows on this machine reserves TCP ranges covering 6400-6499, so the package default/fallback bridge range cannot bind. Qualification used port 6600, outside the excluded ranges.

Evidence:
- MCP server discovery: PASS, 48 tools + 18 static resources + 6 resource templates.
- Editor bridge log: `StdioBridgeHost started on port 6600. (OS=WindowsEditor, server=10.3.0)`.
- VGate `unity__read_console`: PASS end-to-end through the MCP server and Unity Editor bridge.
