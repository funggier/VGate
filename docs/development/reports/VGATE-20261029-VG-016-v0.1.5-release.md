## Scope

VG-015 and VG-016 deliver:

- Typed per-machine persistent settings registry and safe configure/forget lifecycle
- Five stable MCP administration/invocation tools in addition to three existing gateway control tools
- Automatic Windows process/installer/registry discovery hints for Clip Studio, Blender, Unity, Godot, Roblox and MonoGame
- Safe manual project-path fallback for Godot and MonoGame where no unique project is detectable
- No arbitrary MCP command/argument/remote-URL editing through the management tools
- Per-machine state in ignored `local-secrets/provider-connections.json`, separate from tunnel credentials
- Dynamic provider reconnect and digest cache invalidation
- Stable `vgate_provider_invoke` for newly connected providers in an existing MCP session
- `@hono/node-server@2.1.5` security override, dependency audit clean

A detected executable does not guarantee its MCP bridge/editor plugin is available. No full-disk search is performed. User-managed settings are validated and never silently derived from an arbitrary executable.
