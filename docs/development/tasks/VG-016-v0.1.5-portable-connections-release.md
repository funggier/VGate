## CGate copying policy

CGate is a separate local deployment of the same VGate repository. Use fast-forward Git synchronization for tracked files, then `npm ci` and `npm run build` inside CGate, instead of copying the entire directory.

Never overwrite or copy from VGate:

- `CGate-mcp/.git` (maintain its own Git checkout)
- `CGate-mcp/vgate.local.json`, other `*.local.json`
- `CGate-mcp/local-secrets/*` including tunnel credentials and settings
- `CGate-mcp/mcp-conf*.yaml`
- `CGate-mcp/tunnel-client.exe`
- `CGate-mcp/runtime/*`, `logs/*`
- `CGate-mcp/.env*`

Before and after synchronization, compare the hashes of CGate's existing connection and tunnel state. Only copy or derive missing per-machine registry settings from CGate's **own** existing config.
